A collection of focused, hands-on exercises demonstrating how common Business Analyst tools support requirements documentation, process modelling, Agile work management, and API understanding.

These are **tool-practice exercises using simulated scenarios**, not full client implementations. They complement the larger [IT Service Request Management Business Analyst Case Study](https://github.com/sarthak-jaykar/IT-Service-Request-Management-BA-Case-Study), which brings multiple BA activities together in one end-to-end analysis.

## Project index

| Tool / BA activity | Exercise | Evidence and skills demonstrated |
|---|---|---|
| **Confluence — requirements documentation** | [IT Helpdesk Request Portal](Confluence-Mini-Project/IT-Helpdesk-Mini-Project/) | Business context, stakeholders, functional and non-functional requirements, user story, acceptance criteria, page hierarchy |
| **Draw.io — process analysis** | [Online Food Order Process](Drawio-BPMN-Mini-Project/Online-Food-Order-BPMN/) | AS-IS process, issue identification, TO-BE process, swimlanes, gateways and process flows |
| **Jira — Agile delivery support** | [Commerce Order Management](Jira-Mini-Project/Commerce%20Order%20Management/) | Epic, user stories, acceptance criteria, priorities, sprint workflow, bug tracking and basic JQL |
| **Postman — API testing awareness** | [JSONPlaceholder API Testing](Postman-API-Mini-Project/JSONPlaceholder-Testing/) | GET/POST requests, parameters, JSON payloads, response checks and negative testing |

## How these exercises fit a BA workflow

- **Understand and document:** capture the business context, requirements, and acceptance criteria in Confluence.
- **Analyse and improve:** represent a process, identify issues, and communicate a proposed flow using Draw.io.
- **Support delivery:** organise requirements and track work through Jira.
- **Understand system behaviour:** inspect API requests and responses with Postman to build integration and testing awareness.
