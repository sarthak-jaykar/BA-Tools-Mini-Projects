# BA Tools Mini-Projects

A collection of small, practical exercises demonstrating common Business Analyst tools and deliverables. Each mini-project is self-contained and includes evidence/screenshots and a short explanation.

## Projects

| Tool | Mini-project | Focus |
|---|---|---|
| Confluence | [IT Helpdesk Request Portal](Confluence-Mini-Project/IT-Helpdesk-Mini-Project/) | Project overview, stakeholder context, requirements, user stories, acceptance criteria and page hierarchy |
| Draw.io / BPMN | [Online Food Order Process](Drawio-BPMN-Mini-Project/Online-Food-Order-BPMN/) | AS-IS analysis, process issues and TO-BE process modelling |
| Jira | [Commerce Order Management](Jira-Mini-Project/Commerce%20Order%20Management/) | Epic, stories, acceptance criteria, backlog, sprint workflow, bug and JQL |
| Postman | [JSONPlaceholder API Testing](Postman-API-Mini-Project/JSONPlaceholder-Testing/) | GET/POST requests, parameters, response checks and negative testing |

## Purpose

These are focused tool-practice projects, not full client implementations. They complement the larger [IT Service Request Management BA Case Study](https://github.com/sarthak-jaykar/IT-Service-Request-Management-BA-Case-Study) by showing tool-specific evidence.
